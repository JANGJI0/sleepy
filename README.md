# 슬리피 브랜드 홈페이지

Next.js App Router와 TypeScript로 구현한 반응형 메인·기업/브랜드 소개 페이지입니다.

## 실행

Node.js 20.9 이상에서 실행하세요.

```sh
npm ci
npm run dev
```

## 검증 및 프로덕션 실행

```sh
npm run build
npm run typecheck
npm start
```

Vercel에서 이 저장소를 가져오고 Next.js 프리셋을 선택해 배포할 수 있습니다.

## 구조와 범위

- `app/page.tsx`: 메인, 기업 소개 및 제품·FAQ·문의 준비 영역. 메뉴는 같은 페이지의 해당 영역으로 이동합니다.
- `content/home.json`: 기업 소개 및 콘텐츠 등록 상태. 승인된 제품 사진·상세 설명·FAQ·문의 채널·구매 주소가 없어 준비 상태를 표시합니다. 콘텐츠 등록 시 해당 UI 연결 작업이 필요합니다.
- `app/globals.css`: PC·태블릿·모바일 레이아웃. 히어로는 CSS 추상 그래픽이며 제품 사진이 아닙니다. 외부 폰트·이미지 요청은 없습니다.
- `app/loading.tsx`, `app/error.tsx`: 페이지 로딩 및 오류 복구 화면. 정적 페이지이므로 일반 접속에서는 로딩 화면이 나타나지 않을 수 있습니다.
- 본문 건너뛰기, 키보드 포커스, 한국어 문서 언어, 섹션 제목, 움직임 줄이기 설정을 지원합니다.
- 제품 상세, 외부 구매 연결, 문의 접수, 관리자 화면은 이번 첫 화면 구현에 포함하지 않습니다.
